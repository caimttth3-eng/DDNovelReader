# 多多朗读 · 安卓端同步开发指南

> 本文是给安卓（Flutter）工程照做就能落地的实现指南，以桌面端 **v2.2.8** 为基准。
> 协议细节与字段定义见同目录的 `安卓互通指南.md`；本文补充**代码怎么组织、每个文件写什么、
> 怎么和桌面端互测**，含 `source` 字段与 `v1/sources/` 书源文件互通（缺这一步，安卓独有
> 的书在桌面上永远拉不下来）。

---

## 0. 落地目标（做完这几件事就算对接成功）

| 能力 | 安卓端要做的事 | 验收方式 |
| --- | --- | --- |
| 记录互通 | 每本书按 `ck2` 算 `content_key`，上传 `v1/books/<key>.json` | 桌面 `同步` 后进度跟上 |
| 进度互通 | `progress = {chapter_idx, char_offset, percent}` 三元组，量纲与桌面一致 | 两端打开同一本书定位到同一位置 |
| 书签互通 | 按 `id` 并集合并，保留较新 `created_at` | 两端各有 1 条 → 同步后各 2 条 |
| **书源互通** | 记录写 `source` 字段 + 上传 `v1/sources/<key><ext>` | 安卓独有的书在桌面同步后自动进书架 |
| **反向拉取** | 桌面有、安卓没有的书，下载源文件解析入书架并套上远端进度 | 安卓书架多出这本书且能直接读 |

## 1. 工程与环境

- Flutter 3.x（Dart 3），Android `minSdk 21` 以上即可，不需要任何 WebDAV 原生插件。
- 依赖只加两个：

```yaml
dependencies:
  http: ^1.2.0
  crypto: ^3.0.3        # 只在自测里算 sha1 用；用 dart:convert + 自写 sha1 也可省掉
```

- 目录规划（照着建，后面代码直接对应）：

```
lib/
  sync/
    dav_client.dart      # WebDAV 5 个方法 + 书源文件读写
    content_key.dart     # ck2 指纹（必须与桌面端逐字节一致）
    book_record.dart     # 远端记录 ↔ 本地书的字段映射
    sync_engine.dart     # 先拉后推 + 远端独有拉取 + 源文件补传
    sync_store.dart      # 本地库接口（你用自己的 sqflite/JSON 实现）
```

- 网络权限：`android/app/src/main/AndroidManifest.xml`

```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
```

## 3. content_key（`lib/sync/content_key.dart`）

**必须与桌面端逐字节一致**，否则同一本书会变成两条记录。

```dart
import 'dart:convert';
import 'package:crypto/crypto.dart' as crypto;

String normText(String s) => s.replaceAll(RegExp(r'\s+'), '');

/// title：书籍显示名（原样，仅去空白）
/// chapterCount：解析结果的章数
/// chapterTexts：每章正文（不含章节标题行），按顺序
String contentKeyOf(String title, int chapterCount, List<String> chapterTexts) {
  final full = normText(chapterTexts.join());
  final sample = full.length > 2000 ? full.substring(0, 2000) : full;
  final raw = 'ck2|${normText(title)}|$chapterCount|$sample';
  final digest = crypto.sha1.convert(utf8.encode(raw)).toString();
  return digest.substring(0, 16);
}
```

### 自测向量（写完先跑这三条，一条不对就别往下做）

| 书名 | 章节数 | 每章正文（`\n` 为换行） | 期望 key |
| --- | --- | --- | --- |
| 测试书甲 | 2 | `第一章 开端\n正文一。`、`第二章 转折\n正文二。` | `cf56d613ba8d7b65` |
| 测试书乙 | 1 | `楔子\n只有一章的正文。` | `a28620303fae9a0b` |
| 带空格 的书名 | 2 | `第一章\n  第一行  正文\n第二行。`、`第二章\n末章正文` | `268958ab9d9e816f` |

```dart
void _selfTestKeys() {
  assert(contentKeyOf('测试书甲', 2, ['第一章 开端\n正文一。', '第二章 转折\n正文二。'])
      == 'cf56d613ba8d7b65');
  assert(contentKeyOf('测试书乙', 1, ['楔子\n只有一章的正文。']) == 'a28620303fae9a0b');
  assert(contentKeyOf('带空格 的书名', 2, ['第一章\n  第一行  正文\n第二行。', '第二章\n末章正文'])
      == '268958ab9d9e816f');
}
```

> `Dart` 的 `RegExp(r'\s+')` 覆盖空格、`\t`、`\n`、`\r` 与全角空格 `\u3000`，
> 与桌面端 Python 的 `\s` 结果一致；不要把 `trim()` 当成去空白，标题中间的空格也要去掉。

## 4. WebDAV 客户端（`lib/sync/dav_client.dart`）

用 `dart:io` 的 `HttpClient`，好处是能单独关掉证书校验（自建 WebDAV 用自签名证书时）。

```dart
import 'dart:convert';
import 'dart:io';
import 'dart:typed_data';

class DavEntry {
  final String name;
  final bool isDir;
  final int size;
  DavEntry(this.name, this.isDir, this.size);
}

class DavException implements Exception {
  final int status;
  final String message;
  DavException(this.status, this.message);
  @override
  String toString() => 'DavException($status): $message';
}

class DavClient {
  DavClient({
    required this.base,
    required this.user,
    required this.pass,
    required this.remoteDir,
    this.verifyTls = true,
    Duration? timeout,
  }) {
    _hc = HttpClient()..connectionTimeout = timeout ?? const Duration(seconds: 20);
    if (!verifyTls) {
      _hc.badCertificateCallback = (cert, host, port) => true;
    }
  }

  final String base;       // https://dav.jianguoyun.com/dav/
  final String user;
  final String pass;
  final String remoteDir;  // DDNovelReader
  final bool verifyTls;
  late final HttpClient _hc;

  static const maxSourceBytes = 512 * 1024 * 1024; // 512MB，与桌面一致

  String get _auth => 'Basic ${base64Encode(utf8.encode('$user:$pass'))}';

  /// 逐段转义：中文目录名只能转义一次
  Uri uri(String rel) {
    final segs = <String>[
      ...remoteDir.split('/').where((s) => s.isNotEmpty),
      ...rel.split('/').where((s) => s.isNotEmpty),
    ];
    final root = base.replaceAll(RegExp(r'/+$'), '');
    return Uri.parse('$root/${segs.map(Uri.encodeComponent).join('/')}');
  }

  Future<HttpClientResponse> _send(
    String method,
    Uri u, {
    Map<String, String>? headers,
    List<int>? body,
  }) async {
    final req = await _hc.openUrl(method, u);
    req.headers.set(HttpHeaders.authorizationHeader, _auth);
    headers?.forEach((k, v) => req.headers.set(k, v));
    if (body != null) {
      req.headers.contentLength = body.length;
      req.add(body);
    }
    final resp = await req.close();
    return resp;
  }

  Future<Uint8List> _readBytes(HttpClientResponse resp) async {
    final builder = BytesBuilder(copy: false);
    await for (final chunk in resp) {
      builder.add(chunk);
    }
    return builder.takeBytes();
  }

  Future<String> _readText(HttpClientResponse resp) async =>
      utf8.decode(await _readBytes(resp), allowMalformed: true);

  /// 列目录（Depth 1）；目录不存在返回空列表
  Future<List<DavEntry>> propfind(String rel) async {
    const body = '<?xml version="1.0" encoding="utf-8"?>'
        '<D:propfind xmlns:D="DAV:"><D:prop><D:resourcetype/>'
        '<D:getcontentlength/></D:prop></D:propfind>';
    final resp = await _send('PROPFIND', uri(rel), headers: {
      'Depth': '1',
      'Content-Type': 'application/xml; charset=utf-8',
    }, body: utf8.encode(body));
    if (resp.statusCode == 404) {
      await resp.drain();
      return [];
    }
    if (resp.statusCode != 207) {
      final msg = await _readText(resp);
      throw DavException(resp.statusCode, msg);
    }
    final text = await _readText(resp);
    final entries = <DavEntry>[];
    for (final m in RegExp(r'<(?:D:|d:|[a-z0-9]+:)?response\b[^>]*>(.*?)</(?:D:|d:|[a-z0-9]+:)?response>',
            dotAll: true, caseSensitive: false)
        .allMatches(text)) {
      final block = m.group(1) ?? '';
      final hrefMatch = RegExp(r'<(?:D:|d:|[a-z0-9]+:)?href\b[^>]*>(.*?)</(?:D:|d:|[a-z0-9]+:)?href>',
              dotAll: true, caseSensitive: false)
          .firstMatch(block);
      if (hrefMatch == null) continue;
      final href = hrefMatch.group(1)!.trim();
      final isDir = block.toLowerCase().contains('collection');
      final sizeMatch = RegExp(r'<(?:D:|d:|[a-z0-9]+:)?getcontentlength\b[^>]*>(\d+)<')
          .firstMatch(block);
      final path = Uri.parse(href).path;
      final segs = Uri.parse(href).pathSegments;
      final name = segs.isEmpty ? '' : Uri.decodeComponent(segs.last);
      if (name.isEmpty || path.isEmpty) continue;
      entries.add(DavEntry(name, isDir, sizeMatch == null ? 0 : int.parse(sizeMatch.group(1)!)));
    }
    return entries;
  }

  /// 建目录，已存在（405）视为成功
  Future<void> mkdirs(List<String> rels) async {
    for (final rel in rels) {
      final resp = await _send('MKCOL', uri(rel), body: const <int>[]);
      await resp.drain();
      if (resp.statusCode == 405 || resp.statusCode == 301) continue;
    }
  }

  Future<Uint8List?> getBytes(String rel) async {
    final resp = await _send('GET', uri(rel));
    if (resp.statusCode == 404) {
      await resp.drain();
      return null;
    }
    if (resp.statusCode != 200) {
      final msg = await _readText(resp);
      throw DavException(resp.statusCode, msg);
    }
    return _readBytes(resp);
  }

  Future<String?> getText(String rel) async {
    final bytes = await getBytes(rel);
    return bytes == null ? null : utf8.decode(bytes, allowMalformed: true);
  }

  Future<int> putBytes(String rel, List<int> data, {String contentType = 'application/octet-stream'}) async {
    final resp = await _send('PUT', uri(rel), headers: {'Content-Type': contentType}, body: data);
    await resp.drain();
    if (resp.statusCode >= 300) throw DavException(resp.statusCode, 'PUT $rel failed');
    return resp.statusCode;
  }

  Future<void> putJson(String rel, Map<String, dynamic> rec, {bool atomic = true}) async {
    final json = const JsonEncoder.withIndent(' ').convert(rec);
    const ct = 'application/json; charset=utf-8';
    if (!atomic) {
      await putBytes(rel, utf8.encode(json), contentType: ct);
      return;
    }
    final partRel = '$rel.part';
    await putBytes(partRel, utf8.encode(json), contentType: ct);
    final resp = await _send('MOVE', uri(partRel), headers: {
      'Destination': uri(rel).toString(),
      'Overwrite': 'T',
    });
    await resp.drain();
    if (resp.statusCode >= 300) {
      // 服务器不支持 MOVE：删掉 .part 再直写
      final del = await _send('DELETE', uri(partRel));
      await del.drain();
      await putBytes(rel, utf8.encode(json), contentType: ct);
    }
  }

  Future<void> delete(String rel) async {
    final resp = await _send('DELETE', uri(rel));
    await resp.drain();
  }

  /// 测试连接：能列出 v1/books 就算通（不存在目录返回 404 也算通）
  Future<List<DavEntry>> testConnection() async {
    await mkdirs(['v1', 'v1/books', 'v1/sources', 'v1/devices']);
    return propfind('v1/books');
  }

  void close() => _hc.close(force: true);
}
```

注意几点：

- `Destination` 必须是**完整绝对 URL**，且同样逐段转义；不要直接把 `uri()` 的 `toString()` 再包一层 `Uri.encodeFull`。
- PROPFIND 的 XML 命名空间前缀各服务器写法不同（`D:`、`d:`、无前缀），上面的正则会三种都吃。
- `.part` 结尾的文件名一律忽略，不当成书记录。

## 5. 本地库接口（`lib/sync/sync_store.dart`）

同步引擎不直接碰你的数据库，只需要你实现这 6 个方法：

```dart
import 'dart:typed_data';
import 'book_record.dart';

/// 本地一本书的轻量视图（同步只需要这些）
class LocalBook {
  final String id;             // 本机主键（路径或 uuid 均可，只在本机用）
  final String contentKey;     // 首次同步算好后持久化
  final String title;
  final String author;
  final String format;         // 'txt' / 'epub' / 'pdf'
  final String path;           // 源文件路径
  final int totalChars;
  final int chapterCount;
  final List<String> chapterTexts;   // 用于算 key；可只给前几章拼接
  final Progress progress;
  final List<Bookmark> bookmarks;
  final double lastReadAt;

  LocalBook({
    required this.id,
    required this.contentKey,
    required this.title,
    required this.author,
    required this.format,
    required this.path,
    required this.totalChars,
    required this.chapterCount,
    required this.chapterTexts,
    required this.progress,
    required this.bookmarks,
    required this.lastReadAt,
  });
}

abstract class SyncStore {
  Future<List<LocalBook>> allBooks();

  /// 更新进度 / 书签 / contentKey；实现里只改这几个字段，不要重建书
  Future<void> updateBook(String id,
      {String? contentKey,
      Progress? progress,
      List<Bookmark>? bookmarks,
      double? lastReadAt});

  /// 把远端源文件落成新书；返回落盘后可用源文件路径
  Future<String> saveSourceBytes(Uint8List bytes, String ext, String contentKey);

  /// 解析刚落盘的源文件，返回章节数、总字数与每章正文（不含标题行）
  Future<(int chapterCount, int totalChars, List<String>>) parseFor(
      String path, String format);

  /// 入书架（标题必须用远端记录的 title，不要用文件名推）
  Future<void> addBook({
    required String id,
    required String contentKey,
    required String title,
    required String author,
    required String format,
    required String path,
    required int totalChars,
    required int chapterCount,
    required Progress progress,
    required List<Bookmark> bookmarks,
    required double lastReadAt,
  });

  Future<void> setLastSync(double unixSeconds);
}
```

> `parseFor` 就是你现有导入流程里的解析动作，抽成函数即可复用；注意返回的正文必须与桌面端
> 口径一致：**每章正文首尾相接、不含章节标题行**。实在拿不到逐章正文时，用整本正文去掉所有
> 标题行后的文本按同一规则取前 2000 字也可以，但要确保两端分章结果相同。

## 6. 同步引擎（`lib/sync/sync_engine.dart`）

```dart
import 'dart:convert';
import 'dart:io';
import 'dart:typed_data';

import 'content_key.dart';
import 'dav_client.dart';
import 'book_record.dart';
import 'sync_store.dart';

class SyncReport {
  int pushed = 0;
  int pulled = 0;
  int imported = 0;
  int sourceUploaded = 0;
  List<String> remoteOnly = [];
  List<String> log = [];
  bool ok = false;
  String error = '';
}

class SyncEngine {
  SyncEngine({
    required this.client,
    required this.store,
    required this.deviceName,
    required this.deviceId,
    this.onLog,
  });

  final DavClient client;
  final SyncStore store;
  final String deviceName;
  final String deviceId;
  final void Function(String)? onLog;

  void _log(String s) {
    onLog?.call(s);
  }

  Future<SyncReport> sync() async {
    final r = SyncReport();
    try {
      await client.mkdirs(['v1', 'v1/books', 'v1/sources', 'v1/devices']);

      // 1. 远端记录
      final remote = <String, RemoteRecord>{};
      for (final e in await client.propfind('v1/books')) {
        if (e.isDir || !e.name.endsWith('.json') || e.name.endsWith('.part')) continue;
        final key = e.name.substring(0, e.name.length - 5);
        final text = await client.getText('v1/books/${e.name}');
        if (text == null) continue;
        try {
          final rec = RemoteRecord.fromJson(
              jsonDecode(text) as Map<String, dynamic>);
          if (rec.schema != 1) {
            _log('跳过 schema=${rec.schema} 的记录：$key');
            continue;
          }
          remote[key] = rec;
        } catch (err) {
          _log('远端记录解析失败 $key：$err');
        }
      }

      // 2. 本地索引
      final local = <String, LocalBook>{};
      for (final b in await store.allBooks()) {
        var key = b.contentKey;
        if (key.isEmpty) {
          key = contentKeyOf(b.title, b.chapterCount, b.chapterTexts);
          await store.updateBook(b.id, contentKey: key);
        }
        local[key] = b;
      }

      // 3. 先拉
      for (final entry in remote.entries) {
        final key = entry.key;
        final rec = entry.value;
        final mine = local[key];

        if (mine == null) {
          final got = await _importRemote(key, rec, r);
          if (!got) r.remoteOnly.add(rec.title.isEmpty ? key : rec.title);
          continue;
        }

        final localUpd = _updatedAt(mine);
        if (rec.updatedAt - localUpd > 0.5) {
          await store.updateBook(mine.id,
              progress: rec.progress,
              bookmarks: _mergeBookmarks(mine.bookmarks, rec.bookmarks),
              lastReadAt: rec.updatedAt);
          r.pulled++;
          _log('↓ ${rec.title}');
        }
      }

      // 4. 后推（拉取可能改了进度，重新取一遍）
      final afters = <String, LocalBook>{};
      for (final b in await store.allBooks()) {
        afters[b.contentKey] = b;
      }

      for (final entry in afters.entries) {
        final key = entry.key;
        final b = entry.value;
        final rec = _buildRecord(b);
        await client.putJson('v1/books/$key.json', rec.toJson(deviceName, b.format));
        r.pushed++;
        _log('↑ ${b.title}');
      }

      // 5. 源文件：只补远端缺的
      final have = <String>{};
      for (final e in await client.propfind('v1/sources')) {
        if (!e.isDir) have.add(e.name.toLowerCase());
      }
      final uploads = <String>[];
      for (final entry in afters.entries) {
        final key = entry.key;
        final b = entry.value;
        final ext = _extOf(b.format);
        final name = '$key$ext'.toLowerCase();
        if (have.contains(name)) continue;
        final bytes = await _readLocalSource(b.path);
        if (bytes == null) continue;
        if (bytes.length > DavClient.maxSourceBytes) {
          _log('「${b.title}」源文件超过 512MB，已跳过');
          continue;
        }
        try {
          await client.putBytes('v1/sources/$key$ext', bytes);
          r.sourceUploaded++;
          uploads.add('$key$ext');
        } catch (err) {
          _log('上传源文件失败「${b.title}」：$err');
        }
      }
      if (uploads.isNotEmpty) _log('↑ 书源文件 ${uploads.length} 个');

      // 6. 设备登记
      try {
        await client.putJson('v1/devices/$deviceId.json', {
          'schema': 1,
          'device_id': deviceId,
          'device_name': deviceName,
          'last_sync': DateTime.now().millisecondsSinceEpoch / 1000.0,
          'book_count': afters.length,
          'platform': 'Android',
        }, atomic: false);
      } catch (err) {
        _log('设备登记失败：$err');
      }

      await store.setLastSync(DateTime.now().millisecondsSinceEpoch / 1000.0);
      r.ok = true;
    } catch (err) {
      r.error = '$err';
      _log('同步失败：$err');
    }
    return r;
  }

  // ---------- 远端独有：下载源文件入书架 ----------
  Future<bool> _importRemote(String key, RemoteRecord rec, SyncReport r) async {
    final src = rec.source;
    final ext = (src?['ext'] as String?)?.toLowerCase() ?? '';
    final size = (src?['size'] as num?)?.toInt() ?? 0;
    if (size > DavClient.maxSourceBytes) {
      _log('「${rec.title}」源文件过大，已跳过');
      return false;
    }

    final candidates = <String>[if (ext.isNotEmpty) ext, '.txt', '.epub', '.pdf'];
    Uint8List? bytes;
    String usedExt = '';
    for (final e in candidates) {
      bytes = await client.getBytes('v1/sources/$key$e');
      if (bytes != null) {
        usedExt = e;
        break;
      }
    }
    if (bytes == null) {
      _log('远端「${rec.title}」没有源文件，暂不能下载');
      return false;
    }

    final path = await store.saveSourceBytes(bytes, usedExt, key);
    final parsed = await store.parseFor(path, usedExt.replaceAll('.', ''));
    final newKey = contentKeyOf(rec.title, parsed.$1, parsed.$3);
    if (newKey != key) {
      _log('远端「${rec.title}」内容指纹不一致，已跳过');
      return false;
    }

    await store.addBook(
      id: path,
      contentKey: key,
      title: rec.title.isEmpty ? key : rec.title,
      author: rec.author,
      format: usedExt.replaceAll('.', ''),
      path: path,
      totalChars: parsed.$2,
      chapterCount: parsed.$1,
      progress: rec.progress,
      bookmarks: rec.bookmarks,
      lastReadAt: rec.updatedAt,
    );
    r.imported++;
    _log('↓ 新增 ${rec.title}');
    return true;
  }

  // ---------- 本地 → 记录 ----------
  RemoteRecord _buildRecord(LocalBook b) {
    double upd = b.lastReadAt;
    for (final bm in b.bookmarks) {
      if (bm.createdAt > upd) upd = bm.createdAt;
    }
    final src = _sourceMeta(b);
    return RemoteRecord(
      contentKey: b.contentKey,
      title: b.title,
      author: b.author,
      format: b.format,
      totalChars: b.totalChars,
      chapterCount: b.chapterCount,
      progress: b.progress,
      bookmarks: _mergeBookmarks(const [], b.bookmarks),
      updatedAt: upd,
      source: src,
    );
  }

  double _updatedAt(LocalBook b) {
    var upd = b.lastReadAt;
    for (final bm in b.bookmarks) {
      if (bm.createdAt > upd) upd = bm.createdAt;
    }
    return upd;
  }

  Map<String, dynamic>? _sourceMeta(LocalBook b) {
    if (b.path.isEmpty) return null;
    final ext = _extOf(b.format);
    return {
      'ext': ext,
      'size': _fileSize(b.path),
      'name': _baseName(b.path),
    };
  }

  List<Bookmark> _mergeBookmarks(List<Bookmark> a, List<Bookmark> b) {
    final map = <String, Bookmark>{};
    for (final bm in [...a, ...b]) {
      final old = map[bm.id];
      if (old == null || bm.createdAt > old.createdAt) map[bm.id] = bm;
    }
    final list = map.values.toList()
      ..sort((x, y) => x.createdAt.compareTo(y.createdAt));
    return list;
  }

  String _extOf(String format) {
    switch (format.toLowerCase()) {
      case 'epub':
        return '.epub';
      case 'pdf':
        return '.pdf';
      case 'docx':
        return '.docx';
      default:
        return '.txt';
    }
  }

  int _fileSize(String path) {
    try {
      return File(path).lengthSync();
    } catch (_) {
      return 0;
    }
  }

  String _baseName(String path) {
    final segs = path.split(Platform.pathSeparator);
    return segs.isEmpty ? path : segs.last;
  }

  Future<Uint8List?> _readLocalSource(String path) async {
    final f = File(path);
    if (!await f.exists()) return null;
    final len = await f.length();
    if (len > DavClient.maxSourceBytes) return null;
    return f.readAsBytes();
  }
}
```

`_fileSize` / `_baseName` / `_readLocalSource` 都是类内私有方法（用 `dart:io` 的 `File`），
不需要额外依赖。

## 7. 接入点（只改这四处）

1. **导入书成功后**：立即算 `content_key` 并写进本地记录；
   `store.addBook(...)` 里同步保存 `chapterCount` 与每章正文（或保存解析结果缓存）。
2. **阅读进度变化**：沿用你现在的节流保存（如滚动停顿 1~2 秒）把 `progress` 落盘，
   同时刷新 `lastReadAt = now()`；**不要**每次翻页就调同步。
3. **书签新增 / 改备注**：`id` 用 `DateTime.now().microsecondsSinceEpoch.toString()`
   （桌面端用 `str(time.time_ns())`，同为字符串即可），`created_at` 写 Unix 秒。
4. **启动 + 每 10 分钟**：与桌面一致，启动后跑一次，再起 `Timer.periodic`；
   同步中加锁，避免两次并发（`_running` bool 或 `Completer`）。

```dart
Future<void> runSync() async {
  if (_running) return;
  _running = true;
  try {
    final report = await engine.sync();
    if (report.imported > 0) await reloadShelf();   // 有新书才刷书架
    _logLines = report.log;
  } finally {
    _running = false;
  }
}
```

## 8. 设置页字段

与桌面端同名同义，方便用户两边照抄：

| 字段 | 说明 |
| --- | --- |
| 服务器地址 | 例 `https://dav.jianguoyun.com/dav/`，允许带路径前缀 |
| 账号 / 密码 | 只存本机（`flutter_secure_storage` 或私有目录），不写远端 |
| 远端目录 | 默认 `DDNovelReader`，**必须与桌面填写完全一致** |
| 设备名 | 默认取机型，只用于记录里的 `device` 与设备登记 |
| 校验 HTTPS 证书 | 自建自签名证书时关掉（`verifyTls=false`） |
| 自动同步 | 启动一次 + 每 10 分钟一次 |

「测试连接」按钮：`client.testConnection()` 成功即提示"连接成功"，
401 提示"账号或密码错误，或服务器未开启 Basic 鉴权"，404 只代表目录还没建（会自动建）。

## 9. 安卓特有的坑

1. **文件路径**：Android 10+ 用 SAF 选书时 `path` 可能是 `content://` URI，`File(path)` 读不到。
   导入时就把源文件**复制一份到应用私有目录**（`getApplicationDocumentsDirectory()/books/`），
   同步只读这份副本；`source` 的 `name` 用用户原始文件名。
2. **后台被杀**：`Timer.periodic` 在后台会被 Doze 掐掉。要么只在前台同步，要么用
   `WorkManager` 起 15 分钟级任务；同步本身是幂等的，被杀后下次重跑不会出问题。
3. **网络切换**：4G 下上传几十 MB 源文件容易超时，把 `connectionTimeout` 设 20s、
   并在 WiFi 下才补传源文件（记录照常推）。
4. **中文目录名**：`uri()` 已经是逐段 `Uri.encodeComponent`，不要再整串 `encodeFull`，
   否则 `DDNovelReader` 里的中文会变成 `%25E4...`。
5. **自签名证书**：`badCertificateCallback` 只在 `verifyTls=false` 时打开，
   开关要在设置页明示；`http` 包的 `IOClient` 不支持这个开关，所以本文用 `HttpClient`。
6. **JSON 编码**：统一 `utf8`，`Content-Type: application/json; charset=utf-8`；
   服务器按字节存，不要用 `latin1` 回退。
7. **时区**：`updated_at` 只用 Unix 秒浮点，`DateTime.now().millisecondsSinceEpoch / 1000.0`；
   两端设备时间偏差过大会让"新者胜"判错。

## 10. 与桌面端互测（照这个顺序做，10 分钟能验完）

准备：一台电脑跑桌面端 v2.2.8（设置 → 数据同步 填好同一远端），一台安卓机跑新包。

1. **key 一致性**：同一份 txt 两端各自导入，在日志里打印 `content_key`，必须完全相同。
   不同就先查 `chapter_texts` 是否含章节标题行、章数是否一致。
2. **安卓独有 → 桌面拉取**：安卓导入一本新书 → 安卓「立即同步」→ 桌面「立即同步」，
   桌面书架应多出这本书，打开能读到同一章，进度是安卓那边的。
3. **桌面独有 → 安卓拉取**：反过来重复一次，安卓书架多出书且能直接读。
4. **进度双向**：桌面读到第 40 章 → 桌面同步 → 安卓同步，安卓打开定位到第 40 章；
   安卓读到第 60 章 → 同步 → 桌面同步后前进到第 60 章，不回拽。
5. **书签并集**：两端各加 1 条 → 双向同步后各 2 条；同一 id 改备注 → 保留较新那份，不重复。
6. **老数据**：桌面上那批只推过记录、没有源文件的老记录，安卓同步时日志应出现
   "没有源文件，暂不能下载"，书架不出现打不开的空书。
7. **异常**：密码写错 → 提示 401；断网中途 PUT → 远端无残留 `.part`；
   服务器不支持 MOVE → 自动退回直写。

对应验收看 `安卓互通指南.md` 第 7 节那份清单，逐条打勾即可。
