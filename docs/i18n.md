# 界面国际化（i18n）说明

> 本文档记录多多朗读（DDNovelReader）界面翻译的实现方式、覆盖范围与特殊约定，
> 供以后添加新语言或补充翻译时参考。

## 1. 实现机制

核心文件：`novelreader/i18n.py`

- `T(中文原文)` —— 唯一的翻译入口。**以中文为 key**，按当前语言查表返回译文；
  中文模式或字典未收录时**原样返回中文**（安全降级，不会出现空白/报错）。
- `set_lang(lang)` / `get_lang()` —— 设置/读取当前语言（`"zh"` / `"en"`）。
- `_EN` 字典 —— `{中文原文: 英文译文}`，新语言仿照加 `_XX` 字典并在 `T()` 中分支。

所有 UI 文件统一这样引入：

```python
from .i18n import T as _T
```

用户可见文案写法：`text=_T("上一章")`、`title=_T("提示")` 等。
**动态拼接（f-string）** 写成模板 + `.format()` 或 `%`：

```python
_T("已选 {sel} 本 · 缓存中 {caching} 本 · 音频缓存总大小 {size}").format(sel=sel, caching=caching, size=...)
_T("《%s》 共 %d 句，缺失 %d 句（分布在 %d 章）：%s") % (title, total, miss, chs, detail)
```

## 2. 语言切换入口

- 位置：**关于界面 → 界面语言**（`Language`）下拉，`中文` / `English`。
- 存储：`storage.set_setting("ui_lang", "zh"|"en")`，保存在 library.json 的 `settings.ui_lang`。
- 生效方式：**重启软件生效**（tkinter 运行中整体换语言风险高，采用重启最稳）。
- 启动读取：`gui.py __init__` 中 `set_lang(self.settings.get("ui_lang", "zh"))`，必须在 `_build_ui()` 之前。

## 4. 特殊约定（容易踩坑）

1. **配置键不翻译**：`settings` 里存的键（`theme="护眼"`、`paragraph_mode` 数值等）永远保持中文原值。
   主题下拉的做法是 **显示值翻译 + 选值反查映射**：
   ```python
   values=[_T(k) for k in THEMES]              # 显示 Day/Eye/Night/Cream
   _rev = {_T(k): k for k in THEMES}
   theme = _rev.get(self.theme_cb.get(), self.theme_cb.get())   # 选英文→存中文键
   ```
2. **更新记录（Changelog）**：tab 标题翻译（`更新记录`→`Changelog`），**正文（版本历史）永远中文不译**。
3. **快捷键说明（Shortcuts）**：不走 `_T`，直接用**中英双语**硬编码——
   `version_info.SHORTCUTS` 为三元组 `(快捷键, 中文, 英文)`，显示 `中文 / 英文`，两种语言模式都一样。
4. **语音名**：`Edge·晓晓` 品牌名不译，仅前缀 `本地·` → `Local`（`_friendly_voices` 中处理）。
5. **下拉列表值**：空行模式 `不压缩/合并为一行/清理所有行` 已翻译；语言下拉的 `中文/English` 是语言名本身，不译。
6. **按钮宽度**：英文膨胀约 1.5-2 倍，固定 `width=` 的按钮英文超长会截断，新增翻译后需检查
   （可运行 `_width_check` 思路：`T(text)` 后按显示宽度与 `width` 比较，超宽就加大 width）。
7. **f-string 陷阱**：批量替换正则只处理字面量 `text="..."`，`text=f"..."` 必须手改（写成模板+format）。

## 5. 添加新语言的步骤

1. `i18n.py` 增加 `_XX = {中文: 译文}` 字典，`T()` 中加 `if _LANG == "xx": return _XX.get(s, s)`。
2. `set_lang()` 的白名单加 `"xx"`。
3. 关于界面语言下拉 `values` 加语言名。
4. 检查 `_width_check` 类超宽按钮。
5. 中英双语区（快捷键说明）如需第三语言，扩展 `SHORTCUTS` 元组并改 `dialog_ui.py` 渲染循环。

## 6. 当前遗留（未翻译，可后续补充）

- 缓存管理 tab 内的说明文字（如「书籍分章解析结果，删除后下次打开需重新解析」、
  「缓存总大小：xxx（自定义位置）」）——属 f-string/未包裹文案，第一版保留中文。
- 版本历史正文（有意保留中文）。
- 主题下拉 `_set_theme` 之外若有其他地方直接 `theme_cb.set(中文键)` 需同步处理（已处理两处）。
