# 多多朗读 v2.2.8

这一版是两个新功能：**数据同步**（书架、阅读进度、书签在多台电脑之间互通，也能和安卓版互通）与**阅读统计**（今天读了多少、这周读了多少，一眼看清）。

## 更新说明

- 新增「数据同步」（设置 → 数据同步）：填一个支持 WebDAV 的网盘（坚果云 / Nextcloud / 群晖 / Alist 等）就能把书架、阅读进度、书签在多台电脑之间互通，也能和安卓版互通；开启后每 10 分钟自动同步一次，不用再装第三方同步软件
- 同一本书换个位置也认得出：按书名、章节数和正文开头自动配对，两台电脑各自导入同一个文件就能对上同一本书，进度和书签照样合并，原有书架和缓存不用迁移
- 换电脑不用手动搬家：另一台记录过、本机还没有的书，同步时会自动把原文件取回来、分好章放进书架，并恢复到上次读到的位置和书签
- 不占网盘空间：只同步书架信息、阅读进度、书签和小说原文件，解析缓存与整本语音缓存（动辄几十 GB）一律不上传
- 不会互相覆盖丢数据：阅读进度以最近读过的那台为准，书签两边合并、各自的笔记都保留；任一端删掉的书，另一端同步后也会移除（重新导入即视为恢复）；断网中途失败不会写坏数据，下次接着同步
- 新增「阅读统计」（设置 → 阅读统计）：今日朗读时长、今日阅读字数、今日软件开启时长、连续阅读天数四张卡片，加本周七天柱状图和累计摘要，读了多少一目了然
- 统计怎么算：只有真正在播放时才计朗读时长（暂停、停止不算），字数按实际读过去的位置累加、拖进度条跳过的不算；每天朗读满 1 分钟或读满 200 字就算今天读过，连续天数不会因为早上没打开就清零
- 新功能的界面文案与设置入口图标已同步五种语言（简体、繁体、英文、日文、韩文）

## 升级提示

- 直接覆盖旧版本即可：书架、阅读进度、书签、缓存全部沿用，无需重新导入书籍
- 数据同步需要自备一个 WebDAV 网盘；不想用可以完全不碰，软件行为与之前一致
- 阅读统计只记在本机 `stats.json`，不上传、不参与同步

## 下载与安装

**Windows（单文件版）**：`DDNovelReader_v2.2.8_Windows.exe`

1. 下载后双击即可运行（自解压式，启动稍慢但便携，无需安装）
2. 若系统提示「Windows 已保护你的电脑」，点击「更多信息」→「仍要运行」

**Windows（onedir 版，推荐低配 / 机械硬盘用户）**：`DDNovelReader_v2.2.8_Windows_onedir.zip`

1. 解压得到 `多多朗读` 文件夹
2. 进入文件夹，双击 `多多朗读.exe` 运行（运行库随包存放，启动秒开，不向临时目录解压）

**macOS**：`DDNovelReader-macOS_v2.2.8.dmg`（推荐）或 `DDNovelReader-macOS.zip`

1. **DMG**：双击挂载 → 把 `DDNovelReader.app` 拖入「应用程序」文件夹
2. **ZIP**：双击解压得到 `DDNovelReader.app`，拖入「应用程序」文件夹
3. 首次打开若提示「无法验证开发者」：右键 app → 打开 → 再次点击「打开」；或在 系统设置 → 隐私与安全性 中点「仍要打开」
4. 若提示「已损坏，无法打开」：打开终端执行 `sudo xattr -dr com.apple.quarantine /Applications/DDNovelReader.app` 后重试

**Linux**：`DDNovelReader_v2.2.8_Linux.zip`

1. 解压得到可执行文件后，在终端进入文件所在目录
2. 加执行权限：`chmod +x DDNovelReader`
3. 运行：`./DDNovelReader`
4. 本地语音朗读需安装 espeak：Ubuntu/Debian 执行 `sudo apt install espeak`，Fedora 执行 `sudo dnf install espeak-ng`（Edge 在线语音无需安装）

## 数据存放位置

- **Windows**：`%APPDATA%\DDNovelReader\`
- **macOS / Linux**：`~/DDNovelReader/`

主要数据：`library.json`（书架 / 阅读进度 / 设置）、`cache/`（书籍解析缓存与源文件备份）、`tts_cache/`（整本语音缓存，可在「关于 → 缓存管理」自定义位置）、`stats.json`（阅读统计）。

## 使用数据同步

1. 打开「设置 → 数据同步」，填 WebDAV 地址、账号、密码与远端目录（如坚果云的应用密码）
2. 点「测试连接」确认可写，再点「保存」
3. 其他电脑填同一套地址与目录，即可互相看到书架、进度与书签；也可勾选启动自动同步（每 10 分钟）
