# 多多朗读 v2.3.1

这一版补上了 epub 书的插图：书里本来就有的封面和插图会显示在正文里，点一下还能看大图。

## 更新说明

- 书本里的插图现在能看了：用 epub 格式的书，打开后封面和插图会显示在正文里。
- 整页的大图单独占一块，夹在句子中间的小图放到段落末尾，不会把文字挤乱。
- 只有书里本来带的图片会显示；图片要用手机流量联网去取的那种，不去取，照样能正常读。
- 修复：有些插图打开是一块黑色方块，现在按纸张底色铺开，和书页颜色一致。
- 新增：点一下插图就弹出大图，滚轮能放大缩小，双击回到刚好放满屏幕，按 Esc 关闭。
- 插图会被存进缓存目录，清理缓存时会一起清掉，切换缓存位置时跟着一起搬走。

## 几点说明

- **只做带插图的文字书**：轻小说、网文的封面和插画都会显示；整本都是图片的漫画书不在这一版范围内，仍然是按文字读。
- **图片存在缓存里**：插图存在「缓存目录」下面的一个图片文件夹里。清缓存会连插图一起清掉，下次打开这本书时自动从原书里重新取出来，不用你再做什么。
- **换电脑 / 手机同步**：同步只传书架、读到第几页、书签和书本身，不传插图文件；新设备拿到书之后自己解出来。
- **不联网取图**：书里如果写的是网上的图片地址，为了不偷偷用流量、也不拖慢打开速度，这种图不会去下载。

## 升级提示

- 直接覆盖旧版本即可：书架、阅读进度、书签、语音缓存都接着用。
- 第一次打开以前读过的 epub 书时，会重新解一遍（多了插图），之后就正常了。
- 只有 epub 有插图；txt / docx / pdf 等格式的显示方式没有变化。

## 下载与安装

**Windows（单文件版）**：`DDNovelReader_v2.3.1_Windows.exe`

1. 下载后双击就能用（不用安装，第一次打开会稍微慢一点）
2. 如果系统提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」

**Windows（解压版，电脑比较旧或硬盘是机械盘时推荐）**：`DDNovelReader_v2.3.1_Windows_onedir.zip`

1. 解压得到一个 `多多朗读` 文件夹
2. 进去双击 `多多朗读.exe`（打开快，不用每次解压）

**macOS**：`DDNovelReader-macOS_v2.3.1.dmg`（推荐）或 `DDNovelReader-macOS_v2.3.1.zip`

1. **DMG**：双击打开 → 把 `DDNovelReader.app` 拖到「应用程序」文件夹
2. **ZIP**：双击解压出 `DDNovelReader.app`，拖到「应用程序」文件夹
3. 第一次打开如果说「无法验证开发者」：右键 app → 打开 → 再点一次「打开」
4. 如果说「已损坏，无法打开」：打开终端执行 `sudo xattr -dr com.apple.quarantine /Applications/DDNovelReader.app` 再试

**Linux**：`DDNovelReader_v2.3.1_Linux.zip`

1. 解压后在终端进入文件所在文件夹
2. 给执行权限：`chmod +x DDNovelReader`
3. 运行：`./DDNovelReader`
4. 想用本机语音朗读要先装 espeak：Ubuntu/Debian 执行 `sudo apt install espeak`，Fedora 执行 `sudo dnf install espeak-ng`（用在线语音不用装）

## 数据存放位置

- **Windows**：`%APPDATA%\DDNovelReader\`
- **macOS / Linux**：`~/DDNovelReader/`

里面有什么：

- `library.json` — 书架、读到第几页、所有设置
- `cache/` — 书的解析缓存（可以在「缓存管理」里改到别的盘）
- `cache/art/` — 书里的插图（跟着缓存目录走，清缓存时会一起清）
- `cache/sources/` — 自动备份的原书文件
- `cache/lan/` — 局域网同步用的文件（同步记录 + 手机传过来的书）
- `tts_cache/` — 整本语音缓存（可以改到别的盘）
- `stats.json` — 阅读统计
