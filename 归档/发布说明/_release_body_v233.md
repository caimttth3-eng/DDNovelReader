# 多多朗读 v2.3.3

这一版给阅读区加了两样：一是**翻页**（像纸质书那样一页一页翻，也能继续用原来的滚动），二是**正文简繁转换**（一键把整本书切成繁体或简体）。

## 更新说明

- 阅读区新增「翻页」：可选「滚动 / 翻页-无动画 / 翻页-滑动 / 翻页-覆盖」，在工具栏第二行切换，立即生效并停在原来读到的位置。
- 翻页模式下，滚轮、PageUp / PageDown 都是整页翻；点一下屏幕左三分之一往回翻，点右三分之一往后翻（工具栏「点击翻页」可以关掉）。
- 每页都从完整的行开始，页底被切到的那半行用纸张底色遮住，不会出现半截字。
- 换字号、换行距、拉大或缩小窗口后，每页能放多少行会自动重算，不会把正在读的句子丢掉。
- 朗读时分页联动：页内读字视口完全不动，读到页底（含长句读到一半）才按所设动画整页翻；句首直接落到后页时也会整页补翻，不再把句子滚到窗口顶部。
- 新增「简繁」：正文可一键「简体→繁体」或「繁体→简体」，只换字不换词，不做台湾用词替换。
- 简繁严格一字对一字：阅读进度、书签、朗读高亮、插图位置都不会错位。
- 修复 EPUB / HTML 章节标题里有换行（如「第二章 / 青牛镇」）时只显示「第X章」、丢掉后半段的问题，正文里重复的标题行也一并去掉。

## 几点说明

- **朗读仍按原文发音**：简繁只改屏幕上的显示和复制出来的文字，已经缓存好的整本语音不用重新生成，也不会出现新旧音频混用。
- **滚动模式照旧**：不选翻页就还是原来的滚动读法，滚轮、拖动进度条的习惯都不变。
- **不做竖排 / 双栏 / 注音**：这一版只做翻页与简繁，这三项不在范围内。
- **老数据不用迁移**：书架、进度、书签、语音缓存、阅读统计都接着用，覆盖升级即可。

## 升级提示

- 直接覆盖旧版本即可，不需要重装或清缓存。
- 翻页与简繁都是新加的开关，默认仍是「滚动」和「不转换」，升级后打开书跟以前一样。

## 下载与安装

**Windows（单文件版）**：`DDNovelReader_v2.3.3_Windows.exe`

1. 下载后双击就能用（不用安装，第一次打开会稍微慢一点）
2. 如果系统提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」

**Windows（解压版，电脑比较旧或硬盘是机械盘时推荐）**：`DDNovelReader_v2.3.3_Windows_onedir.zip`

1. 解压得到一个 `多多朗读` 文件夹
2. 进去双击 `多多朗读.exe`（打开快，不用每次解压）

**macOS**：`DDNovelReader-macOS_v2.3.3.dmg`（推荐）或 `DDNovelReader-macOS_v2.3.3.zip`

1. **DMG**：双击打开 → 把 `DDNovelReader.app` 拖到「应用程序」文件夹
2. **ZIP**：双击解压出 `DDNovelReader.app`，拖到「应用程序」文件夹
3. 第一次打开如果说「无法验证开发者」：右键 app → 打开 → 再点一次「打开」
4. 如果说「已损坏，无法打开」：打开终端执行 `sudo xattr -dr com.apple.quarantine /Applications/DDNovelReader.app` 再试

**Linux**：`DDNovelReader_v2.3.3_Linux.zip`

1. 解压后在终端进入文件所在文件夹
2. 给执行权限：`chmod +x DDNovelReader`
3. 运行：`./DDNovelReader`
4. 想用本机语音朗读要先装 espeak：Ubuntu/Debian 执行 `sudo apt install espeak`，Fedora 执行 `sudo dnf install espeak-ng`（用在线语音不用装）

**Android / iOS**：桌面版这一版只动阅读区，移动端仍是原版本；手机端装包见移动版 Releases 的 APK / 未签名 IPA（iOS 需 Sideloadly 等工具自签，免费签名 7 天到期后覆盖重签）。

## 数据存放位置

- **Windows**：`%APPDATA%\DDNovelReader\`
- **macOS / Linux**：`~/DDNovelReader/`

里面有什么：

- `library.json` — 书架、读到第几页、所有设置
- `cache/` — 书的解析缓存（可以在「缓存管理」里改到别的盘）
- `cache/art/` — 书里的插图（跟着缓存目录走，清缓存时会一起清）
- `cache/sources/` — 自动备份的原书文件
- `cache/lan/` — 局域网同步用的文件（同步记录 + 手机传过来的书）
- `tts_cache/` — 整本语音缓存（可以改到别的盘）
- `stats.json` — 阅读统计
