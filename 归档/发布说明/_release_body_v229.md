# 多多朗读 v2.2.9

这一版加了「局域网本地同步」：手机和电脑连同一个 Wi-Fi 就能互相同步书架和读到第几页，不用网盘。另外把手机同步用的文件挪进了缓存目录，方便你一次清干净。

## 更新说明

- 新增「局域网本地同步」：手机和电脑连同一个 Wi-Fi，就能互相同步书架和读到第几页，不用网盘。
- 电脑上会开一个小小的同步服务：软件打开它才开，软件关掉它就停，窗口里能看到它有没有在跑。
- 手机只要照抄窗口里显示的「地址、账号、密码、目录」四项，填一遍就能用。
- 书架下面多了一个「一键同步」按钮，按一下就两边对一遍。
- 顺手把 2.2.8 说明里写错的一句话改对了。

> ⚠️ **【重要】手机同步用的文件换地方了**
> 原来放在数据目录，现在挪进缓存目录，跟着你设的缓存位置走（默认 `%APPDATA%\DDNovelReader\cache\lan`）。
> 升级后第一次打开会自动搬过去；也可以在「设置 → 缓存管理 → 同步数据（局域网）」点「迁移旧数据」手动搬。
> 书架、阅读进度、书签、设置都不会变。

## 局域网同步怎么用（三步）

1. 电脑：打开`设置 → 数据同步 → 局域网本地同步`，勾选「开启局域网本地同步」；第一次如弹出防火墙提示，选「允许（专用网络）」。
2. 电脑：窗口里会显示四项——服务器地址（如 `http://192.168.1.7:8930/`）、账号、密码、远端目录。
3. 手机：在安卓端的同步设置里照抄这四项（和填网盘时一模一样），点「测试连接」→「同步」。

> 手机和电脑要在同一个 Wi-Fi；电脑关掉软件，同步服务也会一起停。端口默认 8930，被占用时在电脑上换一个，手机也跟着改。

## 升级提示

- 直接覆盖旧版本即可：书架、阅读进度、书签、缓存都接着用。
- 不想用局域网同步可以完全不管它：默认是关着的，原来的网盘同步也照旧能用。
- 局域网同步只传书架信息、阅读进度、书签和书本身，不传解析缓存和语音缓存。

## 下载与安装

**Windows（单文件版）**：`DDNovelReader_v2.2.9_Windows.exe`

1. 下载后双击就能用（不用安装，第一次打开会稍微慢一点）
2. 如果系统提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」

**Windows（解压版，电脑比较旧或硬盘是机械盘时推荐）**：`DDNovelReader_v2.2.9_Windows_onedir.zip`

1. 解压得到一个 `多多朗读` 文件夹
2. 进去双击 `多多朗读.exe`（打开快，不用每次解压）

**macOS**：`DDNovelReader-macOS_v2.2.9.dmg`（推荐）或 `DDNovelReader-macOS_v2.2.9.zip`

1. **DMG**：双击打开 → 把 `DDNovelReader.app` 拖到「应用程序」文件夹
2. **ZIP**：双击解压出 `DDNovelReader.app`，拖到「应用程序」文件夹
3. 第一次打开如果说「无法验证开发者」：右键 app → 打开 → 再点一次「打开」
4. 如果说「已损坏，无法打开」：打开终端执行 `sudo xattr -dr com.apple.quarantine /Applications/DDNovelReader.app` 再试

**Linux**：`DDNovelReader_v2.2.9_Linux.zip`

1. 解压后在终端进入文件所在文件夹
2. 给执行权限：`chmod +x DDNovelReader`
3. 运行：`./DDNovelReader`
4. 想用本机语音朗读要先装 espeak：Ubuntu/Debian 执行 `sudo apt install espeak`，Fedora 执行 `sudo dnf install espeak-ng`（用 Edge 在线语音不用装）

## 数据存放位置

- **Windows**：`%APPDATA%\DDNovelReader\`
- **macOS / Linux**：`~/DDNovelReader/`

里面有什么：

- `library.json` — 书架、读到第几页、所有设置
- `cache/` — 书的解析缓存（可以在「缓存管理」里改到别的盘）
- `cache/sources/` — 自动备份的原书文件
- `cache/lan/` — 局域网同步用的文件（同步记录 + 手机传过来的书）
- `tts_cache/` — 整本语音缓存（可以改到别的盘）
- `stats.json` — 阅读统计
