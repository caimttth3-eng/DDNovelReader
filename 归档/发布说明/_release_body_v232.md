# 多多朗读 v2.3.2

这一版重做了同步：两台设备同时读同一本书，各自改的进度和书签不再互相覆盖；同步按钮也按方向拆开，点哪个方向就只走哪个方向。

## 更新说明

- 两台设备同时在读同一本书时，各自改的进度和书签不再互相覆盖：谁的改动更新就留谁的，另一边的书签照样保住。
- 同步按钮拆成两个方向：「保存到云端」只把本机改动送上去；「从云端读取」只把云端更新拿下来。书架底部、数据同步里的局域网区块、云端区块都用这一套名字。
- 点同步会先列出差异（将上传几本、将更新几本、将移除几本），确认了才真正写入。
- 修复：书架底部的两个同步按钮曾被列表挤掉，现在固定在「添加书籍」下面一行。
- 同步改成按项合并写入，云端记录不会因为一个字段变动被整条替换。

## 几点说明

- **自动同步照旧**：开机和定时的那次同步仍然是双向的，会自己把两边对齐；新加的两个按钮只用于你想手动单向推 / 拉的时候。
- **删除照样双向**：一边删掉书，另一边同步时会跟着移除，不会因为改了同步方式就复活。
- **老数据不用迁移**：书架、进度、书签、语音缓存都接着用，覆盖升级即可。

## 升级提示

- 直接覆盖旧版本即可，不需要重装或清缓存。
- 第一次手动点「保存到云端」或「从云端读取」时，会先出一份差异清单，确认后才写。

## 下载与安装

**Windows（单文件版）**：`DDNovelReader_v2.3.2_Windows.exe`

1. 下载后双击就能用（不用安装，第一次打开会稍微慢一点）
2. 如果系统提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」

**Windows（解压版，电脑比较旧或硬盘是机械盘时推荐）**：`DDNovelReader_v2.3.2_Windows_onedir.zip`

1. 解压得到一个 `多多朗读` 文件夹
2. 进去双击 `多多朗读.exe`（打开快，不用每次解压）

**macOS**：`DDNovelReader-macOS_v2.3.2.dmg`（推荐）或 `DDNovelReader-macOS_v2.3.2.zip`

1. **DMG**：双击打开 → 把 `DDNovelReader.app` 拖到「应用程序」文件夹
2. **ZIP**：双击解压出 `DDNovelReader.app`，拖到「应用程序」文件夹
3. 第一次打开如果说「无法验证开发者」：右键 app → 打开 → 再点一次「打开」
4. 如果说「已损坏，无法打开」：打开终端执行 `sudo xattr -dr com.apple.quarantine /Applications/DDNovelReader.app` 再试

**Linux**：`DDNovelReader_v2.3.2_Linux.zip`

1. 解压后在终端进入文件所在文件夹
2. 给执行权限：`chmod +x DDNovelReader`
3. 运行：`./DDNovelReader`
4. 想用本机语音朗读要先装 espeak：Ubuntu/Debian 执行 `sudo apt install espeak`，Fedora 执行 `sudo dnf install espeak-ng`（用在线语音不用装）

## 数据存放位置

- **Windows**：`%APPDATA%\DDNovelReader\`
- **macOS / Linux**：`~/DDNovelReader/`

里面有什么：

- `library.json` — 书架、读到第几页、所有设置
- `cache/` — 书的解析缓存（可以在「缓存管理」里改到别的盘）
- `cache/art/` — 书里的插图（跟着缓存目录走，清缓存时会一起清）
- `cache/sources/` — 自动备份的原书文件
- `cache/lan/` — 局域网同步用的文件（同步记录 + 手机传过来的书）
- `tts_cache/` — 整本语音缓存（可以改到别的盘）
- `stats.json` — 阅读统计
