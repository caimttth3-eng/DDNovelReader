# 多多朗读（DDNovelReader）

支持 **Windows / macOS / Linux / Android** 四平台的中文小说阅读器：**TTS 语音朗读**、
主流电子书格式、书架管理、阅读进度自动保存与自动续读、整本语音缓存。
- **Windows**：绿色免安装 exe，双击即用
- **macOS**：DMG 拖入即装（或 ZIP 解压），支持 M 系列与 Intel
- **Linux**：单文件可直接运行
- **Android**：前往 [安卓版发布页](https://github.com/caimttth3-eng/DDNovelReader-Android) 下载

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 主流格式 | txt / epub / mobi / azw3 / pdf / docx / html / zip（自动解包查找内部小说）/ chm（CHM 电子书） |
| CHM 电子书 | 内置 chmlib 解析库（Windows / macOS / Linux 三平台可用），自动抓取章节名与正文、剥离页面脚本与导航杂物，转成专用缓存后阅读；中文路径、GBK/UTF-8 编码自动兼容 |
| TTS 语音朗读 | 默认本地语音（SAPI5，离线），可选 Edge 神经语音（晓晓/云希等 9 种中文音色，需联网）；开始/结束两个按钮；语速按真实倍数可调（0.50×~2.00×，步进 0.05×，如 1.55×，与 Edge 实测语速对齐）；句间隔可调（设为 0 时自动裁剪 Edge 音频自带首尾静音，句间接近无缝）；逐句高亮跟随（高亮固定窗口首行）；Edge 在线朗读 30 句预取缓存跨章节连续预取，章节切换不卡顿；Edge 断网自动回退本地语音 |
| 音量控制 | 功能区音量滑条，通过 Windows Core Audio 控制本进程音量，不影响系统音量和其他软件 |
| 多媒体键 | Windows 下支持蓝牙耳机 / 键盘媒体键控制朗读：播放/暂停键切换、停止键停止（软件为前台窗口时生效，与主流播放器一致） |
| 整本语音缓存 | 提前缓存整本书语音，网络不稳定时减少卡顿；支持按章节选择、暂停/继续、智能播放键（自动检测任务状态）、停止、进度持久化（重启后续传且自动补齐缺失章节）、缓存完成后自动关机；合成失败如实记录进度，不再谎报 100%；新增『验证补全』：重建任务列表逐句比对磁盘，精确报告缺失句数与章节，一键补齐；并发下载线程可配置（3~12，默认 6，超过 6 易被微软限流） |
| 五语言界面 | 简体中文 / 繁體中文 / English / 日本語 / 한국어 一键切换（关于界面「界面语言」下拉，重启生效）；首次启动自动读取系统默认语言并区分简繁（Windows 按区域子语言、macOS/Linux 按 locale：台湾 / 香港 / 澳门系统默认繁体界面，其他语言默认英文），之后尊重用户手选；主界面/对话框/下载管理器/搜索/书签/快捷键说明/缓存管理/主题切换全量翻译（含繁体），更新记录标题多语言、正文保持各语言原文；语音下拉按界面语言过滤（英语界面显示 US/UK 音色，日语/韩语界面显示对应音色） |
| 语音引擎 | 设置→语音引擎：接入 GPT-SoVITS（本地自训练音色）/ vits-simple-api / VOICEVOX / Google / 火山 / OpenAI 兼容 / 自定义 HTTP 等 8 个引擎，每个引擎独立代理开关、安装教程与一键启动命令；GPT-SoVITS 三平台共用同一服务（端口 9880），选目录后播放/整本缓存自动启动本地服务，启动期间显示进度动画提示，就绪后自动继续；外部音色同样支持整本缓存 |
| 控件主题系统 | 6套全控件主题（A米黄暖读 / B深色夜间 / C清爽浅蓝 / D原生微调 / E青绿科技 / F豆沙暖粉），关于界面点击图标进入主题选择 |
| 阅读书页配色 | 白天 / 护眼 / 夜间 / 米黄 四种阅读区配色 |
| 字体设置 | 任意系统字体、字号（10–48）、行距（1.0–3.0）可调，实时生效 |
| 总进度 | 底部进度滑块 + 百分比 + 「第 X 章 / 共 Y 章」+ 总字数，实时更新；拖动滑块跳转；百分比可点击手动输入 |
| 自动保存 | 滚动、翻章、朗读、退出时自动保存阅读进度 |
| 自动续读 | 每次打开自动回到上次阅读位置，并自动打开最近阅读的书 |
| 书架 | Windows 详细信息视图（进度/书名/大小/时间，可排序带箭头）；支持多选：按住左键拖动框选连续多选、Ctrl / Shift 拖动追加、Ctrl+A 全选；右键菜单（打开/复制原文件/复制书名/删除/删除文件，多选时批量删除并显示数量）；书架与阅读区可拖拽调节宽度；默认关闭；导入时自动备份源文件，原文件删除后阅读/重新分章/复制原文件照常，备份缺失时复制原文件置灰 |
| 章节切分 | 三重检测：严格匹配（第X章）/ 分隔线匹配 / 书名前缀匹配（如"书名 第1章"）；另识别正文中穿插的『第X章 标题』内层章节（编号连续时优先按内层真章节分章，支持嵌在正文行中间、分隔符兼容空格/冒号）；支持楔子/序章/番外等；第一章前文字归入"简介"章；分章异常自动诊断：导入异常时弹窗展示原因与前 5 候选标题，可选按候选切分 / 手动输入标题标记 / 保持现状；阅读区右键『重新分章（整本）』按最新规则整本重切 |
| 章节标题 | 阅读区每章开头显示当前章节标题（加大、粗体、居中） |
| 拖拽导入 | 把文件直接拖进书架区即可导入 |
| 书签 + 划线 + 笔记 | 选中文字右键「添加书签/划线」弹出备注框（默认取选中文字），目录区顶部「目录/书签」切换；书签浅绿高亮、一键跳转、右键删除 |

| 书架备份/还原 | 书架底部按钮，一键导出/导入书架、进度、设置与书签（还原前自动备份当前数据） |
| WebDAV 数据同步 | 设置→数据同步：填服务器地址 / 账号 / 密码即可把**书架、阅读进度、书签**在多台电脑之间互通（坚果云 / Nextcloud / InfiniCLOUD / Alist / 自建 WebDAV 均可），也能和安卓版互通；两台电脑各自导入同一本书会自动认成同一本，与文件路径无关；进度以最近读过的那台为准，书签两边合并、笔记不丢；另一台有记录而本机没有的书，同步时自动取回原文件、分好章放进书架并恢复到上次位置；解析缓存与语音缓存不上传（不占网盘），断网中断不会写坏数据；支持启动自动同步（每 10 分钟）与自签名证书开关 |
| 阅读区右键 | 复制 / 百度搜索 / 谷歌搜索 / 必应搜索 / B站搜索 / 抖音搜索 / 百度翻译 / 谷歌翻译 / 搜狗翻译 / 从该段开始朗读 |

## 下载

在 [Releases](https://github.com/caimttth3-eng/DDNovelReader/releases) 页面下载对应平台的最新版，绿色免安装：

- **Windows（单文件版）**：`DDNovelReader_v2.2.9_Windows.exe`，双击即可运行（自解压式，启动稍慢但便携，无需安装）
- **Windows（onedir 版）**：`DDNovelReader_v2.2.9_Windows_onedir.zip`，解压后进入文件夹双击 `多多朗读.exe`（运行库随包存放，**启动秒开**，推荐低配 / 机械硬盘用户；zip 需解压后使用）
- **macOS**：`DDNovelReader-macOS_v2.2.9.dmg`（推荐，拖入即装）或 `.zip`，安装步骤：
  1. **DMG**：双击挂载 → 把 `DDNovelReader.app` 拖入「应用程序」文件夹
  2. **ZIP**：双击解压得到 `DDNovelReader.app`，拖入「应用程序」文件夹
  3. 首次打开若提示「无法验证开发者」：右键 app → 打开 → 再次点击「打开」；或在 系统设置 → 隐私与安全性 中点「仍要打开」
  4. 若提示「已损坏，无法打开」：打开终端执行 `sudo xattr -dr com.apple.quarantine /Applications/DDNovelReader.app` 后重试
- **Linux**：`DDNovelReader_v2.2.9_Linux.zip`，安装步骤：
  1. 解压得到可执行文件后，在终端进入文件所在目录
  2. 加执行权限：`chmod +x DDNovelReader`
  3. 运行：`./DDNovelReader`
  4. 本地语音朗读需安装 espeak：Ubuntu/Debian 执行 `sudo apt install espeak`，Fedora 执行 `sudo dnf install espeak-ng`（Edge 在线语音无需安装）

## 使用步骤

1. 打开程序 → 点击「添加书籍」选择小说文件（支持多选批量导入）
2. 加入书架后自动打开；书架双击书名切换书籍
3. 顶部工具条：上一章 / 下一章 / 目录 / 字体 / 字号 / 行距 / 书页 / 主题 / 音量 / 语速 / 停顿 / 语音 / 定时 / 缓存 / 关于
4. 「开始朗读」从当前位置朗读，朗读时当前句高亮
5. F11 进入全屏模式

## 数据存放位置

数据目录规则：若设置了环境变量 `DOUBAO_NOVEL_DATA` 则优先使用；否则按平台回退：

- **Windows**：`%APPDATA%\DDNovelReader\`（即 `C:\Users\<用户名>\AppData\Roaming\DDNovelReader\`）
- **macOS**：`~/DDNovelReader/`（即 `/Users/<用户名>/DDNovelReader/`）
- **Linux**：`~/DDNovelReader/`（即 `/home/<用户名>/DDNovelReader/`）

目录内容：

- `library.json` — 书架、阅读进度、全部设置
- `cache/` — 书籍解析缓存（可在「缓存管理」自定义到其它盘）
- `cache/sources/` — 源文件备份（导入书籍时自动备份原文件，原文件删除后仍可重解析 / 复制）
- `cache/lan/` — **局域网同步数据**（v2.2.9 起；同步记录 + 手机同步过来的书源文件。升级后首次启动会自动从旧位置 `数据目录\lan` 迁过来，也可在「缓存管理 → 同步数据（局域网）」手动点「迁移旧数据」）
- `tts_cache/` — 整本语音缓存（可在「关于 → 缓存管理」中自定义位置，便于移出系统盘）

## 常见问题

- **C 盘 Temp 里的 _MEI* 文件夹是什么？** 单文件 exe 每次运行解压的临时目录，正常退出会自动删除；只有任务管理器强杀 / 崩溃 / 断电才会残留。v2.1v2 起软件每次启动自动清理超过 1 天的残留，无需手动处理。
- **没有中文语音？** 在 Windows「设置 → 时间和语言 → 语音」中添加中文语音包后重启程序。
- **首次打开界面语言不是中文？** 软件会读取系统默认语言：系统是简体中文 / 繁体中文（台湾、香港、澳门）/ 英文 / 日文 / 韩文则默认对应语言界面，其他语言默认英文；可在「关于 → 界面语言」手动切换。
- **播放 GPT-SoVITS 时弹出「正在启动… GPT-SoVITS」？** 这是正常提示：首次使用（或重启电脑后）软件会自动启动 GPT-SoVITS 本地服务，启动约需 10~60 秒，期间界面不冻结，就绪后自动开始朗读；长时间无响应请到语音引擎检查所选目录是否正确。
- **切换界面语言后没变化？** 语言切换（简体中文 / 繁體中文 / English / 日本語 / 한국어）需重启软件后生效。
- **语音列表里找不到想要的音色？** 语音列表跟随界面语言过滤：中文界面显示中文音色，英文界面显示 US/UK 音色，日文/韩文界面显示对应语言音色；需要使用其他语言音色时，请先切换界面语言再重启。
- **句间停顿调 0 还是有点久？** v2.1v4 起播放前会自动裁剪 Edge 语音音频自带的句首尾静音（合成器固有约 550ms 尾静音 + 190ms 头静音），停顿=0 时句间接近无缝；若停顿明显，多为语速较快时音频内容本身较密，属正常。
- **Edge 语音无声？** 确认网络正常；Edge 语音需联网，断网时自动回退本地语音。
- **朗读卡顿？** 可使用"整本语音缓存"提前缓存，或切换到本地语音；在线朗读跨章处卡顿的问题已在 v2.1v3 修复（预取缓存跨章节连续预取）。**打开软件就卡 / 无响应？** 单文件 exe 每次启动需向临时目录解压约 35MB（机械硬盘 / 杀软扫描下明显），建议改用 **onedir 版**（解压后运行，启动秒开）。
- **整本缓存显示已完成但仍需联网？** 旧版本存在合成失败仍误报 100% 的问题；请在下载管理器使用「验证补全」重建任务并逐句比对磁盘，一键补齐缺失章节（v1.99V3+ 已修复误报）。
- **蓝牙耳机 / 键盘媒体键没反应？** 媒体键仅在 Windows 且软件为前台窗口时生效（与主流播放器一致）。
- **分章不正确？** v1.95 重构分章系统支持"书名 第N章"格式，v1.99V2 进一步识别正文中穿插的『第X章 标题』内层章节，v1.99V3 支持章节标题嵌在正文行中间、分隔符兼容空格/冒号；v2.1v3 起分章异常会弹窗提示（可按候选切分 / 手动输入标题标记 / 保持现状），阅读区右键「重新分章（整本）」可对已导入书籍按最新规则整本重切；书架上的旧书章节数没变化时，右键该书选择「重新分章（整本）」即可。
- **音量滑条无效？** 确保程序正在播放音频（音频会话存在时音量控制才生效）。
- **局域网同步连不上？** ① 确认手机和电脑在同一个 Wi-Fi（不要在访客网络 / 开启了 AP 隔离的路由器）；② 电脑第一次开启时若弹出防火墙提示，选「允许（专用网络）」；③ 手机上的服务器地址要用电脑界面里显示的 IP（`设置 → 数据同步 → 局域网本地同步`），端口、账号、密码、远端目录四项照抄；④ 端口被占用时换一个端口（默认 8930）；⑤ 电脑关闭软件后服务会一起停止，这是设计如此，需要同步时保持软件在运行。
- **局域网同步的数据存在哪？想清掉怎么办？** 存在 `缓存目录\lan\`（默认 `%APPDATA%\DDNovelReader\cache\lan\`，会跟着你在「缓存管理」里改的缓存位置走）。想清掉：`设置 → 缓存管理 → 同步数据（局域网）` 里有「打开文件夹」和「清除」；从旧版本升级上来的数据会在首次启动时自动迁移，也可点那一栏的「迁移旧数据」手动迁移。

## 技术栈

- 界面：Python 标准库 tkinter（Tcl/Tk 8.6）+ ttk 主题
- 朗读：pyttsx3（Windows SAPI5）+ edge-tts 7.3.1（微软 Edge 神经语音）
- 音频播放：Windows MCI（winmm.dll）+ pygame（macOS/Linux 播放、Edge 音频首尾静音裁剪解码）
- 音量控制：pycaw（Windows Core Audio，进程级音量）
- 解析：自写解析引擎（txt/epub/html：zipfile + OPF/spine 解析；mobi/azw3：mobi 库）、pypdfium2（pdf，PDFium 引擎）、python-docx（docx）、zipfile（zip）、chmlib 内置库（chm，Zig 交叉编译 Windows/macOS/Linux 三平台）
- 拖拽：tkinterdnd2（Tcl tkdnd 扩展）
- 系统托盘：pystray（Windows 通知区 / macOS 菜单栏 / Linux 通知区，macOS 后端依赖 pyobjc-framework-Cocoa / Quartz）
- 打包：PyInstaller **双形态**（onedir 秒开版 + onefile 单文件版，内置 Tcl/Tk 与全部依赖，绿色免安装）
