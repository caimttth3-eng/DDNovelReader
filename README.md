# 多多朗读（DDNovelReader）

一款 Windows 本地运行的中文小说阅读器，支持 **TTS 语音朗读**、主流电子书格式、书架管理、
阅读进度自动保存与自动续读、整本语音缓存。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 主流格式 | txt / epub / mobi / azw3 / pdf / docx / html / zip（自动解包查找内部小说） |
| TTS 语音朗读 | 默认本地语音（SAPI5，离线），可选 Edge 神经语音（晓晓/云希等 9 种中文音色，需联网）；开始/结束两个按钮；语速可调；句间隔可调；逐句高亮跟随（高亮固定窗口首行）；Edge 断网自动回退本地语音 |
| 音量控制 | 功能区音量滑条，通过 Windows Core Audio 控制本进程音量，不影响系统音量和其他软件 |
| 整本语音缓存 | 提前缓存整本书语音，网络不稳定时减少卡顿；支持按章节选择、暂停/继续、智能播放键（自动检测任务状态）、停止、进度持久化（重启后续传且自动补齐缺失章节）、缓存完成后自动关机；合成失败如实记录进度，不再谎报 100% |
| 控件主题系统 | 6套全控件主题（A米黄暖读 / B深色夜间 / C清爽浅蓝 / D原生微调 / E青绿科技 / F豆沙暖粉），关于界面点击图标进入主题选择 |
| 阅读书页配色 | 白天 / 护眼 / 夜间 / 米黄 四种阅读区配色 |
| 字体设置 | 任意系统字体、字号（10–48）、行距（1.0–3.0）可调，实时生效 |
| 总进度 | 底部进度滑块 + 百分比 + 「第 X 章 / 共 Y 章」+ 总字数，实时更新；拖动滑块跳转；百分比可点击手动输入 |
| 自动保存 | 滚动、翻章、朗读、退出时自动保存阅读进度 |
| 自动续读 | 每次打开自动回到上次阅读位置，并自动打开最近阅读的书 |
| 书架 | Windows 详细信息视图（进度/书名/大小/时间，可排序带箭头）；支持多选；右键菜单（打开/复制原文件/复制书名/删除/删除文件）；书架与阅读区可拖拽调节宽度；默认关闭 |
| 章节切分 | 三重检测：严格匹配（第X章）/ 分隔线匹配 / 书名前缀匹配（如"书名 第1章"）；另识别正文中穿插的『第X章 标题』内层章节（编号连续时优先按内层真章节分章）；支持楔子/序章/番外等；第一章前文字归入"简介"章 |
| 章节标题 | 阅读区每章开头显示当前章节标题（加大、粗体、居中） |
| 拖拽导入 | 把文件直接拖进书架区即可导入 |
| 书签 + 划线 + 笔记 | 选中文字右键「添加书签/划线」弹出备注框（默认取选中文字），目录区顶部「目录/书签」切换；书签浅绿高亮、一键跳转、右键删除 |
| 全文搜索 | 功能区 🔍 按钮，书内关键词搜索，双击结果跳转定位 |
| 书架备份/还原 | 书架底部按钮，一键导出/导入书架、进度、设置与书签（还原前自动备份当前数据） |
| 阅读区右键 | 复制 / 百度搜索 / 谷歌搜索 / 必应搜索 / 翻译 / 从该段开始朗读 |
| 全屏模式 | F11 或 Alt+Enter 进入；右上角显示当前时间、阅读时间、章节名、总进度；自动隐藏书架与目录（退出按原状态恢复） |
| 定时停止 | 可设置分钟数，到时自动停止朗读 |
| 滚动条统一 | 书架/目录/阅读区/下载管理器/全文搜索/更新记录/快捷键/缓存管理 全部统一扁平黑色滑块样式并加宽（35px），夜间主题自动切换深色 |
| 空行压缩 | 三种模式：不压缩 / 合并为一行 / 清理所有行；段落首行缩进二字 |
| 缓存管理 | 正文缓存 + 音频缓存均可自定义文件夹、一键转移、一键清除、打开文件夹、实时统计大小 |
| 启动体验 | 秒开：窗口约 1 秒显示并带阅读区加载动画，书籍后台加载，不再白屏等待 |
| 窗口 | 默认 1280×720 并居中显示，每次启动固定 |

## 使用步骤

1. 打开程序 → 点击「添加书籍」选择小说文件（支持多选批量导入）
2. 加入书架后自动打开；书架双击书名切换书籍
3. 顶部工具条：上一章 / 下一章 / 目录 / 字体 / 字号 / 行距 / 书页 / 主题 / 音量 / 语速 / 停顿 / 语音 / 定时 / 缓存 / 关于
4. 「开始朗读」从当前位置朗读，朗读时当前句高亮
5. F11 进入全屏模式

## 数据存放位置

- 书架与阅读进度：`%APPDATA%\DDNovelReader\library.json`
- 书籍解析缓存：`%APPDATA%\DDNovelReader\cache\`
- 语音缓存：`%APPDATA%\DDNovelReader\tts_cache\`（可在"关于→缓存管理"中自定义位置）

## 常见问题

- **没有中文语音？** 在 Windows「设置 → 时间和语言 → 语音」中添加中文语音包后重启程序。
- **Edge 语音无声？** 确认网络正常；Edge 语音需联网，断网时自动回退本地语音。
- **朗读卡顿？** 可使用"整本语音缓存"提前缓存，或切换到本地语音。
- **分章不正确？** v1.95 重构分章系统支持"书名 第N章"格式，v1.99V2 进一步识别正文中穿插的『第X章 标题』内层章节；如仍有问题可删除书籍重新导入。
- **音量滑条无效？** 确保程序正在播放音频（音频会话存在时音量控制才生效）。

## 开发说明

### 环境要求
- Python 3.10+
- Windows 10/11

### 安装依赖
```bash
install.bat
```
或手动：
```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

### 运行
```bash
run.bat
```
或手动：
```bash
.venv\Scripts\python -m novelreader.main
```

### 打包 exe
```bash
build.bat
```
或手动：
```bash
.venv\Scripts\python -m PyInstaller --clean 多多朗读.spec
```
产物在 `dist\多多朗读.exe`。

### 运行测试
```bash
.venv\Scripts\python tests\test_core.py
.venv\Scripts\python tests\test_gui.py
.venv\Scripts\python tests\test_features.py
```

## 技术栈

- 界面：Python 标准库 tkinter（Tcl/Tk 8.6）+ ttk 主题
- 朗读：pyttsx3（Windows SAPI5）+ edge-tts（微软 Edge 神经语音）
- 音频播放：Windows MCI（winmm.dll，零第三方依赖）
- 音量控制：pycaw（Windows Core Audio，进程级音量）
- 解析：ebooklib（epub）、mobi（mobi/azw3）、pypdfium2（pdf，PDFium 引擎）、python-docx（docx）、zipfile（zip）
- 拖拽：tkinterdnd2（Tcl tkdnd 扩展）
- 打包：PyInstaller onefile（内置 Tcl/Tk 与全部依赖，绿色免安装）
